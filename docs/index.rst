ImageEditor
===========

.. image:: https://img.shields.io/badge/license-Apache%202.0-blue.svg
   :target: license.html

.. image:: https://img.shields.io/badge/platform-Linux%20%7C%20macOS%20%7C%20Windows%20WSL-lightgrey.svg

|

A versatile **Qt6-based image processing tool** with JSON-history support,
designed to run on Debian Linux and macOS.
It supports both an interactive graphical user interface and a headless
batch mode for server environments.

Developed at the **Institute of Neuroscience and Medicine (INM-1)**,
Forschungszentrum Jülich GmbH, in the framework of the
`BigBrain Project <https://bigbrainproject.org>`_ and the
`Julich Brain Atlas <https://julich-brain-atlas.de>`_.
