# rearrangejson.py - UndoStack Organizer

## Overview
This Python script is designed to process JSON files generated by image editing tools. It reorganizes the `undoStack` to ensure that operations are logically grouped by layers and chronologically ordered within those groups.



## Key Functionality
- **Layer Grouping:** Clusters all commands based on their `layerId` or `newLayerId`.
- **Creation Priority:** Within each layer group, the `LassoCutCommand` (initial creation) is always moved to the top of the block.
- **Chronological Stability:** All subsequent manipulations (e.g., `MoveLayer`, `RotateLayer`, `ScaleLayer`, `WarpLayer`) maintain their original order relative to each other.
- **On-Top Targeting:** Allows a specific Layer ID to be moved to the very end of the stack for priority processing.

---

## Mandatory Parameters
To run a sorting task, you **must** provide these three arguments:

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `--input` | string | Path to the source JSON file. |
| `--output` | string | Path for the resulting sorted JSON file. |
| `--ontop` | integer | The ID of the layer that should be moved to the end of the stack. |

### Example
```bash
python rearrangejson.py --input raw_data.json --output processed_data.json --ontop 2
History & Automation
The script automatically logs successful operations in a hidden .rearrange_history.json file.

View History: python rearrangejson.py --history (shows all previous calls)

python rearrangejson.py --history 5 (shows the last 5 calls)

Repeat Commands: python rearrangejson.py --repeat <index>

Executes the command at the specified index from the history list, saving you from re-typing long file paths.

Troubleshooting
Common Issues
"JSONDecodeError": If the script fails to parse the JSON, ensure the file is not corrupted. The script automatically attempts to fix trailing semicolons (e.g., "data": "";), but other syntax errors must be fixed manually.

"Permission Denied": Ensure you have write permissions for the directory where the --output file is supposed to be created.

"ID not found": If the --ontop ID is not in the file, the script will show a warning and a list of all available IDs. Check if you used the correct ID from the layers section.

Input File Missing: Verify the path to the --input file. Use absolute paths if the script is called from a different directory.

Installation Requirements
Python 3.x

No external libraries required (uses standard json, argparse, os, and datetime modules).
